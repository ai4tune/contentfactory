# AI Agent 工作台改造路线 v1.0

> 状态：已开始实施<br>
> 产品目标：AI 负责读取状态、提出下一步并执行可逆工作，用户负责方向判断和最终确认。

## 1. 改造边界

本次不重写内容计划、知识库、创作、审核、发布记录和视频引擎。AI Agent 是这些现有能力之上的调度层。

固定原则：

- 对话是主入口，结构化页面是结果承载层。
- 聊天记录不是业务数据的唯一副本。
- 按钮和自然语言使用同一套动作协议。
- 查询、检索、推荐和未确认草稿可自动执行。
- 覆盖已确认内容、视频渲染、发布、删除和核心定位变更需要明确确认。

## 2. 目标交互

```text
进入 AI 工作台
  -> 读取企业定位、计划、草稿、审核和发布状态
  -> 给出 1 个主任务和最多 2 个备选任务
  -> 用户点击建议，或直接输入目标
  -> Agent 调用现有业务能力
  -> 结果进入可编辑、可确认的结构化工作区
  -> 更新业务状态，继续给出下一步
```

## 3. 实施阶段

### Agent 1：工作台和下一步

- 首页改为 AI 工作台。
- 展示主任务、推荐理由和最多两个备选动作。
- 增加指令输入，先支持计划、选题、创作、审核、企业资料和视频脚本。
- 导航收缩为 AI 工作台、内容库、企业资料和更多工具。
- 保留所有现有页面作为结果页和备用入口。

### Agent 2：受限工具注册中心

- 封装内容计划、知识检索、Brief、草稿、审核、发布反馈和视频准备工具。
- 每个工具定义输入、输出、准入权限、幂等策略和错误恢复。
- 大模型只能选择白名单工具，不能自由调用任意接口。

### Agent 3：对话运行时

- 增加意图识别、流式输出、工具执行状态和失败重试。
- 持久化会话、消息、Agent Run、工具调用和用户审批。
- 页面刷新后恢复当前目标、正在执行的工作和结果引用。

### Agent 4：结构化结果工作区

- 在对话旁展示计划、选题、Brief、草稿、审核和视频预览。
- 支持编辑、确认、版本恢复和返回原详情页。
- 结果只保存在原有业务对象中，会话仅保存引用。

### Agent 5：核心闭环

- 不知道写什么：推荐选题 -> 选择 -> 匹配资料 -> 草稿 -> 审核。
- 已有想法：识别目标 -> 补齐必要信息 -> 初稿 -> 对话修改。
- 继续任务：找回未完成草稿或待审核内容。
- 今日决策：给出主任务、依据和备选动作。
- 视频准备：生成脚本、匹配 OSS 素材、识别素材缺口，再由用户确认渲染。

### Agent 6：主动运营

- 发布后收集数据和人工反馈。
- 生成周复盘和下周建议。
- 只在用户开启通知后主动提醒。

## 4. Agent 1 验收标准

- 已完成引导的用户进入 `/` 后，不查看菜单也能知道下一步。
- 主任务根据没有计划、待确认计划、待审核草稿、写作中草稿、待创作选题和周计划完成状态正确变化。
- 自然语言指令可以进入对应的现有工作流，不会执行越权操作。
- 视频指令清楚说明当前只支持脚本，不伪装成已经完成自动剪辑。
- 390 px 宽度下无水平滚动，主任务、输入和主操作均可见。
- 所有原有路由保留，原有数据读取和创作流程不受影响。

## 5. 本阶段不做

- 不让大模型自主调用任意后端接口。
- 不自动发布、删除、覆盖已确认内容或渲染付费视频。
- 不删除现有详情页和高级工具。
- 不在 Agent 1 中引入多智能体、语音、长期记忆和主动通知。
