# 付费试点隐私与客户数据生命周期

## 数据边界

每位客户使用独立实例。服务端会保存客户主动确认的账号定位、知识来源索引与引用片段、内容计划、简报、草稿、审核记录、发布反馈、市场收藏和调用元数据。

本地知识库目录仍由浏览器读取：目录句柄和轻量索引保存在该浏览器的 IndexedDB；服务端不会自动复制整个本地文件夹。飞书和其他外部知识源只在客户授权范围内读取。

## 外部服务

客户主动发起功能时，所选知识片段、账号上下文或稿件可能发送给配置的 AI、生图、飞书或市场数据服务。交付方应在客户开始使用前告知所用服务、用途和数据边界，并使用客户同意的企业账号或 API Key。

## 日志和成本观测

系统只记录下列调用元数据：服务类型、接口、模型、开始/结束时间、耗时、成功或失败、缓存命中、输入/输出 token 数和可选成本估算。

调用日志不保存完整提示词、知识库正文或生成稿。错误日志只记录状态和错误类别；运维排障不得临时打印客户正文或密钥。

## 保留、导出与删除

- 试点开始时，与客户约定服务期限、备份保留时间和结束后的删除日期。
- 试点期间按部署清单进行加密存储的离线备份；备份访问权限仅授予交付人员。
- 客户需要迁移时，可交付完整 `CONTENT_FACTORY_DATA_DIR` 备份及校验清单。
- 客户终止服务并确认后，停止实例，删除服务端持久化数据卷、备份卷、离线备份和服务端环境变量。
- 浏览器 IndexedDB、本地知识库文件夹和飞书原文属于客户侧数据，需由客户在对应设备或系统中自行撤销授权或删除。

删除命令：

```bash
npm run data:delete -- --confirm=DELETE_CUSTOMER_DATA
```

这是不可恢复操作。执行前应完成客户确认，并按双方约定决定是否先交付最终备份。
