# 市场与选题链路修复验收（2026-09-10）

## 实现范围

- 市场搜索和作品榜完成后写入 `data/market-history.local.json`，最多保存 100 条快照。此文件属于本地运行数据，不提交 Git。
- 主题搜索恢复最近一次查询，历史入口使用记录 ID 精确恢复平台、关键词、页码和结果；作品榜恢复最后一次快照。
- 灵感与选题展示搜索历史、已获取作品榜及真实爆款收藏。普通搜索结果不标注为热门话题。
- 允许正文为空的爆款记录持久化，状态区分待补充正文、待拆解、已拆解；重复收藏不覆盖已有正文与分析。
- 详情页补充正文后可主动拆解，修改正文会使旧分析失效；分析期间正文变化不覆盖新内容。
- AI 推荐可以选择最多 5 篇已收藏参考，保存上次输入和输出；外部内容作为参考而不是企业事实。候选可加入选题池，重复操作去重。
- `/topics` 兼容跳转到 `/ideas?tab=recommend`，使用同一侧边栏。

## 自动验证

`npm run test:acceptance` 通过：插件 7、核心 API 21、V2 13（含测试组），生产构建通过。两个原有 lint 警告保留。

新增回归：空正文收藏重启后仍在；历史读取不请求上游；正文保存与拆解状态；推荐采纳已收藏正文并保存原始输入（不重复拼接样本）；候选去重；旧路由重定向。

所有接口验证使用隔离的临时数据和模拟 RedFox／AI，不消耗用户额度、不改动真实内容。

## 人工复验

本机浏览器自动化两次均因 `Unable to load browser request-header policy` 无法创建标签。以下点击验收尚需人工完成：

1. 主题搜索一次，刷新并切换页面后返回，确认结果保留。
2. 收藏一条无全文结果，刷新确认已收藏；进入详情补正文、保存、AI 拆解。
3. 在灵感发现页打开不同页码的历史记录；在爆款标签看到同一条收藏。
4. 推荐标签选择收藏样本，生成候选并加入选题池，从选题池进入创作。

## 使用边界

升级前没有快照的查询不能精确恢复；已被旧写入流程过滤掉的收藏无法凭空恢复，可从市场结果重新收藏。仅主动查询或 AI 拆解／推荐消耗相应接口额度。没有提供全文的结果需要插件或人工补充。
