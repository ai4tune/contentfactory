# 行业初始口吻与首次创作验收

日期：2026-10-07。分支：`feat/first-content-experience`，从 `main@371c9af` 开始。本记录覆盖合并前的技术验收；实际生产部署以发布后的版本与域名检查为准。

## 交付行为

普通商家确认经营档案后，进入 `/setup/first-content`：选择咖啡店、木板/地板装修或其他业务，对比三段使用相同已确认事实的表达示例，补充一句偏好，保存预览并确认，然后从三个建议选题开始写第一篇。无需先生成完整 30 天计划。

模板实例记录行业、口吻、v1 与来源，沿用现有风格草稿/确认仓库。保存预览不改变已确认风格；过期页面提交返回 409。换模板保留已确认的客户自定义规则、常用/禁用词及渠道偏好。原品牌资料、自有代表文章与定位预览入口继续可用，不新增第二套品牌档案。

首次选题复用已有选题池、简报、内容项目、AI 审核和人工编辑。项目保存选定风格快照。重复提交使用同一项目，存储时保留已有生成正文，包含用户人工修改。回到首次入口能继续原稿，已有完整计划能力保持可用。

“下载本渠道正文”仅导出当前正文；完整材料包另标“下载项目资料（含简报）”。人工发布仍需用户确认。

## 事实核对与发现的反例

四渠道与快速创作都在生成后独立核对原始资料和已确认经营信息；风格样例、AI 简报、目标人群假设不作为独立事实依据。无来源主张至多自动修正一次；持续失败或核对不可用时不返回生成正文，而保留可重试的失败项目并说明需补充的资料。

第一轮真实模型复测仍放过了污染简报中的“几款果香和坚果风味”。定位后改为逐句拆出主张、查找直接证据，并强调不能从正文反推资料。第二轮发现模型把“未提供价格”改写成“价格还没定好”，继续补齐未知信息不能推导经营状态的规则。以上反例说明二元审核提示并不能天然保证核验可靠。

最终使用当前配置模型与隔离临时数据复测：

| 情况 | 最终结果 |
| --- | --- |
| 仅确认“提供咖啡饮品”的咖啡店 | 首篇完成约 9.1 秒，介绍已知业务，没有款数、风味或作者经历 |
| 仅确认木板与地板装修服务 | 首篇完成约 8.7 秒，未添加案例、参数或服务承诺 |
| 简报夹带几款果香/坚果咖啡和昨天聊天半小时 | 最终正文收缩为真实咖啡业务介绍，不继承污染内容 |
| 原始资料明确确认果香咖啡，价格与经历缺失 | 保留果香，未添加价格状态与经历 |

独立核验的五个固定样例中，无来源风味、数量、亲历和价格状态均返回 unsupported；有直接依据的风味返回 supported。以上是有限真实模型样例，不是全部事实场景的正确率或全面无虚构保证。仍需商家核对最终正文和实际价格、服务边界，模型会增加每次生成的耗时和调用成本。

## 浏览器完整路径

使用同一验收浏览器空间和独立本地资料，完成行业选择、生活方式口吻选择、补充偏好、保存预览、刷新恢复、确认、选首篇、生成、人工改稿、保存历史、实际正文下载与返回找到原稿。

390 像素窄屏检查：页面宽度与文档宽度均为 390，无横向溢出，确认后三个选题均可开始。桌面与窄屏渲染经过截图检查。下载文件只有人工修改后的正文和尾部换行，没有简报、引用说明或原生成正文。

浏览器第一次验收被本地 Basic Auth 弹窗阻断，已停止有问题的验收服务，改用仅监听本机的代理为合成测试账号附上授权。生产授权代码没有修改。收到用户明确继续后恢复原浏览器空间，完成上述路径。模拟模型用于浏览器操作；真实模型使用另一个隔离生产构建实例验证。
