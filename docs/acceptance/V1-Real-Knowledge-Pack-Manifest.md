## 4. 使用前人工确认

每份被选中的资料都应满足：

- [ ] 可以提交给当前配置的 AI 服务处理；
- [ ] 不包含密码、Token、二维码、联系方式或未脱敏个人信息；
- [ ] 其中的客户名称、原话、经营数据和案例允许用于本次内容；
- [ ] `待补证`、推测和计划不会被写成已经发生的结果；
- [ ] 资料仍代表当前定位，没有被更新版本替代；
- [ ] 事实、报价和产品能力可以在发布前再次核对。

如果任一项不能确认，就暂时不选该文件。知识包的目标不是“资料越多越好”，而是让每个关键事实都有明确来源。
