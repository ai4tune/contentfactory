# 知识库文件夹更新与图片读取验收

分支：`fix/knowledge-file-refresh`，基于 `main` 的 `c606f24`。本文记录发布前隔离验收。用户于 2026-10-09 明确授权：“好，先把这个上线吧，因为用户等着用呢”。发布目标为既有 Vercel 项目与 `https://nrgc.xingren.me`，不执行数据迁移或客户资料改写。

## 问题与原因

- 图片此前在扫描文件夹时直接跳过；无文字层 PDF 也被跳过，并非已经证实客户文件过大。
- 点击刷新会重新提取所有文件正文；单份旧文件超时或暂未下载时，会从重建的索引里消失。
- 普通上传入口只接受 MD/TXT，服务端旧协议只接受 TXT/MD/CSV。
- 当前文字网关 `chatapi.weixin.qq.com` 的 DeepSeek 配置实测返回 HTTP 400：`Model only supports text input; received unsupported content type 'image_url'.` 不能直接承担图片识别。模型官方的其他接口能力不代表这个网关的能力。

## 改动后的行为

1. 同一文件夹刷新时，比较文件大小和修改时间；未变化的资料复用原索引，只提取新增或变更文件。显示新增、更新和复用数量。
2. 旧资料暂时读失败时保留原索引和摘要，逐个列出原因。取消扫描或目录整体读取失败时不替换原连接和索引。更换文件夹不复用另一个目录的同名资料。
3. 图片和无文字摘要的 PDF 进入清单，不在扫描时调用 AI。用户预览或选择建档时读取；识别结果在本机缓存，文件变化后失效。照片的可见内容和扫描文字仍需人工核对。
4. 图片识别默认使用既有 `IMAGE_BASE_URL` / `IMAGE_API_KEY` 网关的 `gpt-5-3-mini`；支持另行配置 `VISION_BASE_URL`、`VISION_API_KEY`、`VISION_MODEL`。文字建档继续使用原 `AI_MODEL`。
5. 上传入口接受 PDF、Word、图片和文字。PDF/Word 在浏览器提取文字，图片压缩后识别，每份独立导入。失败文件不阻止其他成功资料；已上传资料保留列表、预览与建档选择入口。
6. 读取页面不自动生成、确认或改写企业档案。刷新清单后仍需选择资料、生成草稿并人工确认。旧资料的未知字段、原创建时间和归属保留。

## 范围与限制

- 图片优先使用 JPG、PNG、WebP，也可读取浏览器能打开的 GIF/BMP；HEIC/TIFF 显示在清单并提示先转换，不自动推荐。
- PDF、Word、图片每份最多 20 MB；扫描或混合 PDF 最多 20 页，请拆分长扫描件。图片压缩到最长边 1600 像素，识别文字需要人工核对。
- 文件夹索引单文件等待最多 15 秒；已选择资料的单份读取最多 3 分钟。图片请求有独立超时和明确错误，服务不可用时不伪造成功结果。
- 本地扫描期间需保持页面打开；建档任务提交成功后才可关闭。此改动不把文件夹变成自动同步，也不读取 PPT 或视频。
