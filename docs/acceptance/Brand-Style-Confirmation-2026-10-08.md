**状态：本地实现与技术验收完成；用户于 2026-10-08 确认结果并明确授权本轮提交、push、合并和流水线上线。发布进行中；真实模型质量与真实客户独立使用持续验证。**

## 本轮交付

- `/brand` 整合品牌资料与自己的历史账号、当前定位、写作风格三个步骤。保留已有知识库、定位、风格、计划和历史稿件入口；切换步骤保留页面内尚未保存的输入。
- 品牌事实须确认；当前经营目标、产品和人群优先，历史采集只作参考。用户可主动将已确认资料带入定位表单，AI 结果需核对后确认。
- 风格支持直接描述、选取自己的资料或含正文的历史内容、上传或粘贴文章提炼；没有明确风格时，可选温柔朋友式、轻松愉快、专业介绍。所有示例仅使用本账号已确认信息。
- 通用模板 v3 提供更新前后对照；查看与保留当前版本不写入，明确保存形成待确认草稿，确认才生效。模板更新保留用户身份、个人规则及优先级、常用词、禁用词、渠道偏好、非模板样例与未知旧字段；陈旧版本请求返回冲突。
- 全国同赛道参考、周边 3/5 公里竞对、评论需求选题、手机照片/截图识别后置。

## 用户本地验证

已启动入口：<http://127.0.0.1:4480/brand>。使用虚构设计工作室、独立临时目录和模拟模型；不读取生产凭据或连接客户空间。模拟模型用于核对流程，不能代表真实模型的风格分析与写作质量。

建议依次检查：

1. 在“品牌资料与历史”查看资料，进入“当前定位”，核对当前目标与历史参考的关系。
2. 在“写作风格”分别试直接描述、自己的文章和模板；切换步骤后检查尚未保存的输入。
3. 从模板查看差异，先保留旧版，再保存草稿、核对、确认；检查个人补充仍在。
4. 刷新找回草稿，使用已确认配置进入第一篇。

重启方式（在本任务工作目录中）：先执行 `npm run build`，再执行 `node ops/preview-brand-style.mjs`。端口 4480 为入口，4481 为模拟模型，4482 为本地应用。
