## 已实现能力

首页对话可以调用 `search_web`、`search_peer_content`、`read_peer_account`、`read_peer_posts`；通过 `load_skill(research)` 使用可信内置研究规则。复用 AI SDK 原生工具循环和现有 Workflow，不接 DeepSeek Harness、地图 MCP 或任意脚本。

Brave 使用服务端 token 请求官方网页搜索接口，最多 8 条，中文优先，可选一周/一个月筛选。取得搜索摘要、补充片段、页面日期与链接，明确不是全文；时间筛选基于索引，不保证首次发布时间。空结果正常保存；服务错误、额度受限、格式错误显示失败，不伪装成空结果。

RedFox 沿用现有官方 API 适配器，小红书支持综合、最新、最多点赞、最多收藏；公众号支持综合、最新、最热，时间只支持不限。账号资料与作品分开请求，需准确平台标识；小红书作品接口使用 redId，不保证与昵称或主页标识相同。不创建订阅或自动跟踪。

每轮最多 4 个不同外部查询，失败也计入范围；每次取首批最多 8 条、无自动翻页。重复成功调用复用保存结果；同一执行轮同参数失败不再次发出外部请求，用户点击继续后才可重试。调研的 RedFox 调用绕过本地旧缓存和失败缓存回退，原市场雷达默认行为保持。

来源片段最多 3200 字，显示标题、链接、平台、作者、已知日期、取得时间和可获得的互动；缺失指标保持未知。来源中的 URL 限 http/https、无凭据，屏蔽密钥回显和不安全协议。Key 不进入客户端或模型上下文。

## 账号持久化与写作衔接

研究保存在当前账号已有聊天工具记录中，没有新表、迁移或读时回填。`search_research` 与 `read_research` 支持跨对话读取历史快照，猜其他账号记录/来源 ID 被拒绝。研究材料不整批写入长期记忆，也不覆盖经营、知识或风格档案。

用户选择候选方向后，具体同行来源通过 `referenceSourceIds` 放进原写作简报的选题参考；本店事实依据仍是已确认经营、知识和用户选中的素材。同行来源不进入本店事实核对资料、知识引用或真实照片来源。资料快照与同行参考在开始写作时冻结；失败恢复仍用同一草稿 ID，不覆盖已有正文。

真实草稿读取又发现归一化完整简报时丢失已保存的选题参考。已让读取保留原项目的参考上下文，不回写数据；隔离测试改用完整有效的简报后先复现失败，再验证修复。

真实模型第一次写作误传整次研究 ID。修复后，工具说明要求先读取来源列表，并区分整次研究 ID 与具体来源 ID；服务端仍严格校验归属。尚未开始写作的参数校验失败允许纠正，已保存资料快照后沿用原参数。新增回归验证同轮纠错成功、没有额外联网；既有保存后故障续跑与单稿去重仍通过。

少量来源只支持选题线索；不同链接、转载或近似摘要不自动计作独立验证。互动数不推算客流、销量或利润；缺正文不能称读完全文，缺日期不称最近，缺样本证据不称爆款。

## 真实接口、模型与本机网络

先前 Brave/高德少量接口初测见升级方案第 22 节。产品真实调研使用 Deepseek-v4-flash 和现有兼容网关，在全新“验收咖啡店”资料中确认的事实只有咖啡饮品与顾客休息座位。

真实模型加载研究方法、读取经营背景，并执行网页与小红书各一次，取得各 8 条来源。小红书本批只有标题/作者/互动，正文基本缺失，且互动偏低；模型没有把它们称为已验证爆款。网页也只有摘要。研究回答给了两个与现有业务相关的方向、实拍需要和材料缺口，并明确尚未查询附近 3～5 公里。

浏览器原生发送选择第二个方向的小红书写作请求。修复来源参数后点击“继续处理”，真实模型在同一任务读取已保存的两条网页来源，创建一篇草稿并完成审核；未重复搜索。最终标题为“附近想坐下来喝杯咖啡，可以知道有这家店”，正文约 150 字，另有三条实拍建议。同行片段保留在选题参考中，事实引用只指向本店确认访谈。草稿待人工核对、没有发布登记；审核为中风险，提示核对留言咨询引导和照片交付要求，不把审核完成当成可直接发布。

实际搜索结果混有空间设计、探店、资讯类内容，需要核对门店身份。初次回答把相似摘要称为两条独立信号，研究规则已补充转载/近似内容与小样本限制；未自动改写历史回答。这不是全国同行排名、完整竞争诊断或稳定效果验证。

真实跨对话复验：通过浏览器“新对话”询问上次研究，模型执行 `search_research` 与两次 `read_research`，读回网页与小红书的 15:47 取得时间；没有外部查询或新稿，明确不能用互动推断到店，也不能把相似/同源摘要计为独立验证。

本机 Node 24.4 直接连接 Brave/RedFox 超时；Python 使用 Mac 系统回环代理可以访问。验收临时转发器 `/tmp/contentfactory-u05-research-relay.py` 仅转发已使用的 Brave/RedFox API 路径，监听 `127.0.0.1:4595`；返回真实供应商数据，不是 mock。不把临时转发作为生产网络架构。

本地凭据放在忽略的 `.env.research-preview`（权限 600），启动器 `/tmp/contentfactory-u05-preview.mjs` 显式加载。没有复制生产数据库、登录凭据或用户空间。预览配置不命名为 `.env.local`，避免 Next 构建提前内联 Supabase 公共配置、干扰隔离测试。构建客户端和可提交文件扫描未发现实际 Key。
