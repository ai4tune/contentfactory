### 重点覆盖

| 场景 | 检查结果 |
| --- | --- |
| 首次访问、未登录和非法输入 | 页面读取零写入；未登录拒绝；非法业务/渠道拒绝 |
| 不知道长期目标、客群和主推产品 | 只确认名称、业务、渠道可进入首篇；不创建定位 |
| AI 预览后只确认业务 | 保留预览为待确认，不采用其客群假设 |
| 无计划、无上传、无已确认风格 | 自有选题可形成带审核结果的草稿；不保存全局默认风格 |
| 修改后重复生成、返回已保存页面 | 复用原项目，保留改稿；读取不改变文件 |
| 已有账号确认不同业务 | 首篇使用本次业务且方向待定，旧定位和风格内容完全不变 |
| 伪造 accountId 与另一个账户 | 服务端按登录归属保存，不改变另一账户记录 |
| 隔离的旧版本样本 | 阻断并统计写入，字段、版本、时间戳、归属和历史入口保留 |
| 既有创作/审核交接 | 相关旧 API 和 V2 交接测试继续通过 |

**U02 后续更新：**首批预览使用模拟模型，固定验收文案曾导致用户自己的选题与正文不匹配。现已切换已有配置的真实模型，顶部显示“本地试用 · 调用真实 AI”。本次试用资料及原稿保留；同题默认找回原项目，测试新生成请使用新选题，不能把旧模拟稿当作真实模型结果。最新交付与限制见 [U02 验收记录](Xiaozhanggui-Writing-Delivery-2026-10-09.md)。

1. 点击“先写一篇”，填写测试业务的真实名称与主营业务，选渠道；其余留空。
2. 点击“确认业务，开始写”，应看到长期方向尚未确认；不要求上传文件或制定计划。
3. 输入自己的选题，先用自然表达生成；检查能进入草稿并看到审核结果。
4. 修改正文后回到首篇重复同一选题，应找回原项目并保留修改；检查历史草稿入口可用。
5. 另走完整访谈，生成 AI 方向后点击“只确认业务，方向稍后再定”，核对建议未被采纳为生效定位。
