# 内容工厂采集助手

Manifest V3 Chrome 扩展，用于主动采集当前已打开账号页或作品页中的可见信息。采集结果既可以送入内容工厂，也可以写入用户自己选择的本地知识库文件夹。

小红书使用专用解析器：账号主页读取账号简介、关注、粉丝、获赞与收藏及最多 20 篇可见作品；作品详情读取标题、正文、标签、图片和公开互动指标。每次提交 AI 分析时，结构化采集快照会保存在本地，供后续运营趋势使用。

扩展加载后会与本地内容工厂的“当前账号”页面建立状态连接。页面会显示插件版本、登录小红书入口、采集步骤和最近一次账号采集结果。

## 安装

1. 在 Chrome 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `extensions/contentfactory-capture`。

## 账号采集

1. 启动内容工厂，默认地址为 `http://localhost:3000`。
2. 打开小红书，点击左侧“我”，进入自己的账号主页。
3. 点击页面右下角“采集当前账号”；如果浏览器不允许自动打开弹窗，再点击工具栏中的扩展。
4. 检查账号名称、简介、粉丝数、内容列表和互动摘要。
5. 如需本地承接，先选择本地资料库文件夹，再点击“保存账号到本地资料库”。
6. 如需内容工厂分析，确认采集结果后生成 AI 定位预览。
7. 修改定位预览，再确认覆盖当前账号。

## 本地资料库

插件使用 Chrome 的文件夹授权能力，只会写入用户主动选择的目录。目录结构如下：

```text
内容工厂采集/
├── README.md
├── 账号/
│   ├── 2026-08-12-账号名称-id.md
│   └── 2026-08-12-账号名称-id.json
└── 爆款/
    └── 2026-08/
        ├── 2026-08-12-文章标题-id.md
        └── 2026-08-12-文章标题-id.json
```

Markdown 面向人工阅读和 Obsidian；JSON 保留完整结构化数据，便于 Codex、WorkBuddy 或其他工具处理。图片暂时保存原始链接，不自动下载到本地。

## 小红书笔记采集

1. 登录小红书并打开一篇笔记详情；
2. 点击页面右下角“预览并保存笔记”，或点击 Chrome 工具栏里的扩展；
3. 核对标题、作者、发布时间、正文、标签、互动指标和图片预览；
4. 选择“网站爆款库 + 本地知识库”“仅本地知识库”或“仅网站爆款库”；
5. 网站保存会生成 AI 拆解，本地保存会生成 Markdown + JSON，不依赖网站运行。

小红书笔记预览与双写能力从 `0.6.0` 起提供。升级插件后请在 `chrome://extensions` 中点击一次“重新加载”。

## 爆款搜索

1. 在小红书页面打开插件，点击“根据当前定位推荐长尾词”；
2. 点击一个长尾词，插件会打开小红书搜索页；
3. 正常滚动页面，加载希望比较的搜索结果；
4. 选择近 3 天、近 7 天或不限时间，设置最低点赞和排序方式；
5. 点击“采集并筛选当前搜索结果”；
6. 打开候选笔记详情，确认完整信息并保存到爆款库或本地知识库；
7. 可把筛选清单另存为本地 Markdown + JSON。

筛选范围只包括当前搜索页已经加载的卡片。搜索卡片没有公开发布时间时会显示“时间未知”；默认不把它当作近 3 天或近 7 天内容，用户可以勾选保留。当前版本为 `0.7.0`。

扩展只读取当前页面 DOM 中已经可见的文本和链接，不会读取密码、绕过登录、解决验证码或在后台批量爬取。

## 小红书指标边界

- 账号公开页：关注、粉丝、获赞与收藏；
- 作品公开页：点赞、收藏、评论，页面有值时读取分享；
- 创作后台：页面可见时读取阅读/播放、曝光、主页访问和新增粉丝；
- 公开页没有展示的阅读或曝光会明确标记为“当前页面未公开”，不会用点赞数代替；
- 采集结果不保存 Cookie、`xsec_token` 或其他临时访问参数。

## 连接独立部署

在扩展的“连接设置”中填写内容工厂地址，点击“保存并授权该地址”。远程部署还必须选择一种服务端授权方式：

- 在 `CAPTURE_ALLOWED_ORIGINS` 中配置扩展的精确 Origin，例如 `chrome-extension://abcdefghijklmnopabcdefghijklmnop`；
- 或设置 `CONTENT_FACTORY_CAPTURE_TOKEN`，并将同一访问码填入扩展。

多个允许的 Origin 使用英文逗号分隔。服务端不使用通配 CORS Origin。
